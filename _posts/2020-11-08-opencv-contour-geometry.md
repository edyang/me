分割以后常有多个候选区域，按最大面积选择不一定找到目标。目标形状、位置与邻接关系应形成明确的筛选条件。

轮廓面积、外接矩形面积与像素计数不同，长宽比受透视和旋转影响。阈值归一化到图像尺寸可以改善多分辨率兼容，却不能替代场景几何关系。

![轮廓筛选：面积、长宽比与位置约束如何组合：处理路径与验证条件](/img/tech-notes/opencv-contour-geometry.svg)

## 一、问题的范围与前提

成像质量、数据分布、算法与业务判断各自有条件。清晰图像提供可观察细节，模型和规则解释输入，业务层决定结果如何使用。视野、曝光、颜色、姿态与输入尺度变化，都可能在模型参数不变时改变结果。

## 二、技术分析与方案取舍

候选属性可按实际业务选择，例如面积占图像比例、长宽比、与边缘的关系以及内部文字。轮廓面积不等于像素计数，空洞和检索模式会影响结果。旋转目标使用轴对齐矩形可能扩大范围，旋转矩形也不能自动处理透视。无合格候选时返回未找到，避免最大区域恰好是背景也被选中。

先固定输入和处理版本，保存必要中间产物，再比较单项变化。裁剪、缩放和配准要携带坐标关系，输出回到原图时检查尺度与偏移。数据按正常和困难条件分别组织，不把反光、遮挡或采集失败从报告中悄悄删掉。

## 三、实现与排查的顺序

1. 保存每个候选的几何属性。
2. 按必要条件先排除无效区域。
3. 再对合理候选进行排序。
4. 无合格候选时返回明确未找到。

按这个顺序保留中间结果，可以区分输入条件、处理过程和最终输出。前一阶段的条件不成立时，先解释对应错误，再继续后面的试验；单次返回成功不足以覆盖整条链路。

### 最小示例

```python
import cv2

result = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
contours = result[-2]
for contour in contours:
    x, y, width, height = cv2.boundingRect(contour)
    area = cv2.contourArea(contour)
```

mask 代表有效二值图，使用倒数第二项提取轮廓以适配相应版本的返回值差异，实际使用前核对安装文档。面积与矩形面积不是同一数值，筛选规则由目标几何决定。

示例聚焦当前技术关系。引用的图片、数据库、消息对象或处理函数，需要由调用环境提供；它不包含完整服务的认证、持久化与并发管理。验证时先用受控输入检查，再纳入应用。

## 四、验证和结果解释

独立样本应覆盖预期工况，逐条预测与错误图支持复盘。分类、检测、定位和异常任务使用各自指标定义，阈值工作点与曲线指标不能混用。性能同时记录冷启动、稳态、尾部耗时和资源峰值，不挑最快一张代表整套系统。

| 需要验证的结果 | 保留的对照 | 不能由此推出的结论 |
| --- | --- | --- |
| 改变图像大小后规则一致 | 固定输入与配置、对应输出 | 一次成功代表所有条件成功 |
| 边缘遮挡不会随意选背景 | 中断前后状态与错误阶段 | 没有报错代表结果正确 |
| 多个候选具有可解释的选择依据 | 恢复后的同条件复测 | 临时恢复代表根因已经消失 |

验证无目标、多候选、边界、遮挡和不同光照。没有有效观测时给出明确失败或待确认，不为每张图强行选一个目标。图像文件真实保存和完整解码也属于链路检查，热力图漂亮不能替代缺陷真值与业务验收。

## 五、适用边界与结论

不能为保证每张图都有结果强行选一个区域。旋转矩形与轴对齐矩形适用条件不同，需按目标姿态选择。

这条路径把“保存每个候选的几何属性”与“无合格候选时返回明确未找到”连在一起，中间保留可复查的条件。实施时优先确认“改变图像大小后规则一致”，再检查“多个候选具有可解释的选择依据”；两者都满足，才能在当前样本与配置范围内评价方案。设备、数据或软件版本改变以后，相关假设需要重新验证。
